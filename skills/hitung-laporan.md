# Skill: Hitung & Laporan
Keywords: hitung, persen, diskon, total, rata-rata, laporan, angka

Saat pertanyaan melibatkan angka:
1. Selalu gunakan tool `calc` — jangan hitung manual di kepala.
2. Tulis ekspresi lengkap (mis. 25/100*1800000).
3. Sajikan hasil + langkah singkat satu baris.
Untuk laporan: rangkum dengan angka yang sudah dihitung via calc, format rapi.
