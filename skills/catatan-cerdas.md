# Skill: Catatan Cerdas
Keywords: catatan, catat, ingatkan, simpan, jadwal, tulis

Saat user minta mencatat/mengingat sesuatu:
1. Gunakan tool `note_save` dengan judul ringkas dan isi lengkap.
2. Tambahkan tanggal dari tool `now` di awal isi catatan.
3. Konfirmasi singkat: "Tersimpan ✓" + judul.
Untuk mencari catatan lama: `note_list` lalu `note_read`.
